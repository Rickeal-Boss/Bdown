关于

Bdown 是开源的 Edge / Chrome 扩展，基于 B 站公开 Web 接口实现解析与下载。
技术要点：WBI 签名（MD5）、DASH 多轨获取、Range 分片并发下载、纯 JS 的 fragmented MP4 无损混流、弹幕 XML → ASS 车道排布。
请仅用于下载你有权保存的内容，并遵守 B 站用户协议。请勿短时间内大量下载，以免触发风控。
项目地址：github.com/Rickeal-Boss/Bdown
